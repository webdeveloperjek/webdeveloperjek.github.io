Ai Agent Optimization thru LLMS.TXT

The project involves optimizing a website for structured interaction with large language models (LLMs) such as ChatGPT, Claude, Gemini, Perplexity, and similar AI-powered agents. Using the emerging LLMS.TXT standard (a protocol similar to robots.txt, but designed for LLMs), the goal is to define how AI agents are permitted to access and use content. This initiative enhances AI accessibility, promotes accurate brand representation, and positions the website for visibility in AI-powered search and conversational interfaces.

Square Space Personal Website

I designed and developed a modern, responsive website for John Na’em Snobar, Director of Advocacy for Palestinian Christians in Australia, with a focus on clarity, accessibility, and strong content presentation.

A key part of this project involved a full content migration from Ghost CMS to Squarespace. I handled the end-to-end migration process, including:

  • Exporting content from Ghost into JSON format
  • Converting and restructuring data into WordPress XML format for compatibility
  • Importing and rebuilding content within Squarespace
  • Migrating pages, blog posts, and contacts while preserving structure and integrity
  • Configuring DNS settings, including CNAME records and monitoring domain propagation for a smooth launch

In addition, I implemented SEO best practices, including optimized meta tags, descriptions, and content structure to improve search visibility and performance.

The final result is a clean, high-performing website that accurately represents the client’s advocacy work while maintaining content consistency across platforms.
